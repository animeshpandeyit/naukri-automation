### GitHub Description

**Naukri Resume Automation** — Automates resume updates on Naukri using Playwright, a persistent browser session, and Windows Task Scheduler. Supports scheduled resume refreshes at **9:30 AM and 5:30 PM on weekdays**, with automatic upload and verification.

**Tech Stack:** Node.js • Playwright • Chromium • Windows Task Scheduler
